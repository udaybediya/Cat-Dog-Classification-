# Cat-Dog-Classification

## Overview

This project is created to test and demonstrate basic Deep learning skills by building a Cat-Dog-Classification model. It focuses on understanding the complete Deep Learning  model workflow from data handling to prediction.

In this model building, we make two models: one we can make from scratch, and the other we make with the VGG16 model. In this VGG16 model we got 90% accuracy, and from scratch, we got 78% accuracy.  

## ▶️ Dataset 

we use In this we use this dataset from Kaggle: [https://www.kaggle.com/datasets/karakaggle/kaggle-cat-vs-dog-dataset].
